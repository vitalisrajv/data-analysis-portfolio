# Customer Analysis Dashboard

## Project Overview
This project analyses customer purchasing behaviour using a fictional retail dataset. The goal is to understand customer spending patterns, identify top-performing cities and product categories, and provide useful business recommendations.

## Tools Used
- Google Sheets
- Pivot Tables
- Charts and visualisations
- Data cleaning and analysis

## Dataset
- 180 transactions
- 40 unique customers
- Year: 2025
- Customer information, products, cities, payment methods and spending

## Key Performance Indicators
- **Total Customer Spending:** KES 6,216,700
- **Total Transactions:** 180
- **Unique Customers:** 40
- **Average Transaction Value:** KES 34,537.22

## Key Findings
- **Top Spending City:** Nairobi – KES 1,556,800
- **Top Product Category:** Electronics – KES 3,173,800
- **Top Payment Method by Spending:** Card – KES 2,011,900
- **Highest Spending Customer:** Customer 021 – KES 582,600

## Business Recommendations
1. Review opportunities to increase sales in Nairobi.
2. Give more attention to the Electronics category.
3. Maintain convenient card payment options.
4. Consider loyalty rewards for high-spending customers.
